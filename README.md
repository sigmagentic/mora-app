# 🔐 MORA App

**MORA exists to capture human values the world cannot see — without ever revealing the people behind them.**

AI already owns almost all human data — behavior, language, preferences, and soon, even synthetic reasoning.

But there is one dataset AI cannot access at scale:
authentic human moral judgment.

When moral decisions are public, people self-censor.
When they’re logged, people lie.
When they’re permanent, people perform.

We are building a zero-knowledge system that captures how humans actually resolve moral dilemmas, without revealing who they are or what they chose.

This creates a new class of data:

- Non-synthetic
- Non-performative
- Non-attributable
- Verifiably aggregated

We believe this “moral signal” will become one of the most valuable datasets for AI alignment, safety, and reasoning — precisely because it cannot be extracted any other way.

## ✨ Features

- **🔑 Passwordless Authentication**: Secure login biometric passkeys (Face ID, Touch ID, Windows Hello) for sybil protection and prventing of social engineering / phishing attacks
- **🔒 PRF Key Derivation**: Biometrics passkeys used to generate data encryption keys
- **🤖 End-to-End Zero Knowledge Design**: frontend and backend built with zero-knowledge principals (NO ONE can see your data EVER!)
- **🤖 Quantum Resistant data encryption**: data is protected from future quantum attacks (i.e. prevents harvest now-decrypto later attacks)
- **🤖 Bot Protection**: Integrated Cap.js CAPTCHA system
- **🔒 JWT Security**: Secure session management
- **🌐 Cross-Platform**: Works across devices and browsers

### Prerequisites

- Node.js 20+
- pnpm (recommended) or npm
